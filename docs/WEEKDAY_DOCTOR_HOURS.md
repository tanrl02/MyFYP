# Different doctor hours by weekday

Implemented19October2026. Staff choose working days and shared sessions, then enable Custom hours for any selected day needing different hours. Each custom day supports one or two same-day sessions. Review lists the effective hours for every working day, then staff confirm the pattern and separately preview/confirm a dated week. Keep editing retains custom hours. Doctors see effective daily hours and actual slots; patients select eligible dated slots through existing booking screens.

Days without custom hours inherit the shared sessions. Turning off a day's custom hours restores the shared sessions. Deselecting a working day removes its custom entry from the form. Duration and capacity are shared across all days. First/second ranges use strict HH:mm Malaysia time, ordered without overlap, with whole slots within each session. Selected days must be distinct and custom entries must reference distinct selected days. Weekly limit200 counts effective custom/inherited hours. Adjacent sessions are allowed without duplicated slots.

API/storage: optional day_sessions list extends the existing staff pattern endpoint and stored JSON. Each entry has weekday0–6 (Monday0), start_time/end_time and optional nullable second_start_time/second_end_time. Entries are normalized into weekday order, so reordered identical retries are safe. Older single/split JSON loads with an empty list without rewriting the original JSON, version or timestamp. No table migration/dependency change. Existing role/doctor scope and pattern version checks remain.

Generation selects effective sessions for each working day. Existing matching slots/bookings are retained; any conflict in any day blocks the batch. Full/partial-day absences skip only overlapping slots. Pattern/availability changes invalidate stale previews. Request retries remain historical and atomic. Changing/removing custom hours or working days never retimes, closes or deletes existing slots/bookings. Previously created slots outside the new pattern need separate staff management. No automatic weekly job, per-day capacity/duration or more than two sessions.
