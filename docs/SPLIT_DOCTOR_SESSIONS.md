# Morning and afternoon doctor sessions

Implemented19October2026. Staff can save one or two daily sessions on the selected working days. In Doctor schedules, enter the first session, enable Add a second session and enter its range. Review and confirm the pattern, then separately preview and confirm a future week. Keep editing retains both ranges. Doctors see both session ranges and their actual dated slots in their own schedule. Patients select generated times through existing booking screens.

Both sessions use the same selected weekdays, slot duration and capacity. Each range must end later on the same Malaysia date and fit whole slots; the second must start at or after the first ends. Both second-session fields are required together, with strict HH:mm validation. Adjacent sessions have no duplicated boundary slot. Combined generation stays limited to200 slots per week. Different weekday session hours, more than two sessions, overnight sessions and automated weekly generation remain outside this increment.

Existing single-session JSON remains stored unchanged and loads with null second-session fields. Optional second_start_time/second_end_time extend the existing staff pattern endpoint and shared types without a database-table migration. Version checks and identical retries cover the complete pattern. Removing the optional session requires review/confirm and only changes future generation. It never removes previously generated slots or bookings.

Generation iterates each session on each working day, leaving the gap empty. Matching existing slots/bookings are retained. Any conflict in either session blocks the entire batch, and changing pattern/availability invalidates a stale preview. Generation and retry records remain atomic. Full-day and partial-day absences skip overlapping slots in either session. Historical generation retries do not create new slots after later pattern edits. Existing slots in a newly introduced lunch gap remain available until staff manages eligible empty slots separately; pattern editing never cancels visits.
